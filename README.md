Overview

Retro Task is a personal productivity application developed to learn Jetpack Compose while exploring how visual design, audio feedback, and user experience can influence motivation and task completion.

Unlike traditional productivity applications that prioritise minimalism, Retro Task embraces a retro-inspired aesthetic influenced by CRT displays and classic video game interfaces.

The project was built primarily for personal use and experimentation rather than commercial release.

⸻

Project Goals

The project had two primary goals:

* Learn and explore Jetpack Compose.
* Create a task management experience that feels satisfying and rewarding to use.

⸻

Features

Task Management

Users can:

* Create tasks
* Track progress
* Update task status
* View historical task activity

Custom Status System

Tasks can move through multiple states:

* Planned
* Underway
* Completed
* Aborted

allowing greater visibility than a simple completed/incomplete workflow.

Retro Visual Identity

The application uses a custom CRT-inspired visual style featuring:

* Retro typography
* Scanline effects
* Terminal-inspired interfaces
* Custom iconography
* Consistent visual language

Audio Feedback

Task interactions are accompanied by sound effects inspired by classic Gran Turismo titles.

The goal was to make completing tasks feel more satisfying and reinforce positive user behaviour through immediate feedback.

⸻

Technical Challenges

Learning Jetpack Compose

The project served as a practical introduction to modern Android UI development using Jetpack Compose.

UI Iteration

Multiple interface layouts were explored throughout development before settling on the final design.

The focus was on balancing usability with a strong visual identity.

Designing for Motivation

A key design goal was creating a productivity application that felt rewarding to use rather than purely functional.

This involved experimenting with visual feedback, sound effects, task states, and interface design.

⸻

Technology Stack

* Kotlin
* Jetpack Compose
* Android SDK
* Material Design Components

⸻

Lessons Learned

This project provided hands-on experience with Jetpack Compose while reinforcing the importance of user experience, feedback loops, and visual identity when designing productivity applications.

It also demonstrated how small design decisions can significantly influence how users engage with software.
